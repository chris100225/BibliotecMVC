# **Bibliotec📚**

# **Objetivo🎯**

# O **Bibliotec** é um sistema web desenvolvido para a gestão e cadastro de livros de uma biblioteca, com controle de acesso e funcionalidades de gerenciamento do acervo.

**Cadastro de Livros:** Permite cadastrar livros contendo Nome do livro, Data de publicação/cadastro, Descrição e Imagem do livro (recurso adicional).  
**Gestão e Listagem:** Exibe a listagem completa de todos os livros cadastrados na biblioteca, permitindo que o usuário edite ou exclua qualquer registro.  
**Autenticação:** Restringe o acesso ao sistema por meio de tela de login com e-mail e senha.

# **Banco de dados🗃️**

Banco de dados **SQL** gerenciado via **SSMS (SQL Server Management Studio)**, responsável por armazenar os dados dos usuários e o acervo de livros.

# **Backend💻**

Desenvolvido no **VS Code** utilizando **C\# .NET 10** sob a arquitetura **MVC (Model-View-Controller)**.

# **Frontend🖍️**

Desenvolvido com **HTML comum**, focado na estruturação das páginas, formulários e exibição da listagem de livros.
